# Molecular-Docking-Project: Quercetin against NUDT5 enzyme
In silico molecular docking, computational and bioinformatics methods driving modern research.
## 📌 Project Overview
This repository contains the computational workflow, input, output and configuration files, and interaction profiling results for **Quercetin** evaluated within the active site of **NUDT5 enzyme**.
## 🛠️ Tools used
1. **ColabFold:** AI-driven 3D protein structure prediction.
2. **Avogadro 2.0:** Ligand preparation.
3. **AutoDockTools:** Macromolecule preparation (receptor preparation).
4. **AutoDock Vina:** Molecular docking engine.
5. **PLIP:** Automated Protein-ligand interaction profiling.
6. **UCSF ChimeraX:** Macromolecule visualization.
7. **PyMol:** Macromolecule visualization
## 📊 Key Findings
* **Predicted Binding Affinity:** **$-8.063\text{ kcal/mol}$**
* **Interacting Hotspots (7 Residues across Chains A & B):** 
  * **TRP46B** (primary hydrophobic/aromatic anchor with parallel $\pi$-stacking and a $3.05\text{ Å}$ H-bond)
  * **ARG51A** (triple H-bond cluster from $2.09\text{ Å} - 2.18\text{ Å}$)
  * **GLU47B**, **THR45B**, **TRP28A**, **LEU98A**, and **GLU112A**
